# 盡調工作台介面

## 版面與視覺

採中性亮白／灰色、細邊框、系統字體與單一藍色主要操作。左側常駐案件列表，提供搜尋與獨立置頂；專案功能位於頂部，讓中央保留工作空間。窄版縮短案件區並讓功能列換行。

- 專案對話為預設入口。起始畫面提供三個查核入口；輸入框隨內容增高。回答區區分角色、表格、文件來源和記憶來源。
- 討論紀錄可收合；查找過程、用量與來源按需展開，長對話提供「回到最新訊息」。
- 記憶範圍與整理狀態位於輸入框上方。管理視窗支援跨案選擇、確認候選、修訂、停用、刪除及開啟來源對話。
- 案件總覽以四步流程與精簡指標呈現。模型、結案與刪除收進案件選項，連線與重建工具預設收合。
- 資料室、資料查核、問題審核、搜尋、訪談筆記採一致的表格、篩選與空白狀態；搜尋及儲存提供等待、成功與失敗回饋。
- 使用台灣投資團隊的用語；技術路徑只在資料追溯等必要位置出現。

## 操作與可及性

本地 Lucide SVG 均搭配文字，裝飾圖示對螢幕閱讀器隱藏。表單有標籤，對話來源保留展開狀態，輸入支援中文組字；空白問題不允許送出。資料上傳可透過鍵盤啟動。視窗提供焦點管理、Escape 關閉及焦點返回，搜尋快捷鍵不干擾開啟中的視窗。

## 驗收邊界

桌面及 390px 窄版檢查版面、案件切換、對話、記憶管理、資料室、總覽、查核、審核、搜尋與訪談筆記。原始分析流程及記憶資料不作為公開介面測試產物提交。模型與多格式測試見 tests/，長期記憶的真實模型實測範圍見 MEMORY_DESIGN.md。
